# 2026-11-27

## AI 官网生成：布局错位 + 图标空白 + 生成后微调

用户截图反馈三类问题，已全部改代码并重新打包 CMS 模块：

1. **布局错位根因**：AI 把内部自带多列网格的整宽微件（`cms.contact` 内含信息/表单/地图三列、`cms.features` 三列卡片、`cms.footer`）塞进 `two-column` 的 6 栅格插槽；`CmsAiWidgetSchema` 没声明整宽约束，`LlmCmsAiDesignerService.ValidateSection` 只在 layoutPreset 命中表时才校验 zone，且未知布局会被 `AppendAiSectionAsync` 静默回退到第一个布局。
   - 新增 `CmsAiWidgetSchema.FullWidthWidgets` / `Icons` 白名单。
   - `LayoutZoneTable` 改为携带每插槽 Span；校验增加「整宽微件必须 12 栅格」「未知布局直接报错」；分块阶段由骨架权威决定 title/anchor/layout，模型只允许补 widgets；prompt 明确整宽/半栏规则。
   - 现场 DB 证据：站点 `ai-1` 的「核心技术优势」= heading(左6)+features(右6)，「联系我们」= contact(左6)+map(右6)。
2. **图标空白根因**：AI 写 `icon: "Cpu"/"HighPerformance"` 等 AppIcon 不支持的名称，`BitIcon` 渲染成空方块。
   - 生成 prompt + 校验限制 `cms.features.items[].icon` 只能用白名单；前端 `CmsFeaturesWidget` 对未知名称兜底 `Check`，历史数据也能显示图标。
3. **生成后 AI 调整**：后端原本只有 `generate-section` / `refine-widget` 返回草稿，没有落库端点，前端也没入口。
   - 新增 `POST /api/cms/ai/append-section/{siteId}`（复用 `AppendAiSectionAsync`）。
   - 设计器新增「AI 微调」弹窗：改写选中微件（调 refine-widget → UpdateWidgetAsync）或追加新区块（generate-section → append-section），中英本地化键已补。

验证：CMS Application/Frontend/根模块编译 0 警告 0 错误；全量测试 74/74；`scripts/build-module.sh cms 1.0.0` 已重打包（backend/frontend DLL + localization 均已更新）。需重启 ApiHost/WebHost 并对 CMS unload/load 后生效；旧的 `ai-1` 站点需重新生成才会应用新布局约束。
